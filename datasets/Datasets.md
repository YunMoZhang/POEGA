# Datasets

We use the following five graph datasets:

1. [Uk-2005](https://networkrepository.com/web-uk-2005-all.php)
2. [IT-2004](https://networkrepository.com/web-it-2004-all.php)
3. [Twitter](https://github.com/ANLAB-KAIST/traces/releases/tag/twitter_rv.net)
4. [SK](https://networkrepository.com/web-sk-2005-all.php)
5. [Subdomain](https://km.aifb.kit.edu/sites/webdatacommons/hyperlinkgraph/index.html) (1st Subdomain Graph)

After extracting the downloaded dataset, rename the file to ```.el``` and convert this raw edge list to a ```.bin``` file, as instructed in the [README.md](../README.md).
